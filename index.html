Step 1

회원가입 및 로그인

회원가입

📱 전화번호 입력
→
🔢 인증코드 입력
→
👤 이름·비밀번호 설정

✅ 가입 완료
  • 전화번호를 입력하면 SMS 인증코드(6자리)가 발송됩니다.
  • 인증코드는 3분간 유효합니다.
  • 인증 완료 후 이름과 비밀번호를 설정하면 가입이 완료됩니다.
  • 비밀번호는 8자 이상, 영문+숫자 조합이 필요합니다.

로그인

가입한 전화번호와 비밀번호로 로그인합니다. 로그인하면 자동으로 대시보드로 이동합니다.

비밀번호 찾기

로그인 화면에서 "비밀번호 찾기"를 누르면 전화번호 인증 후 새 비밀번호를 설정할 수 있습니다.

Step 2

업장 개설 및 직원 초대

업장 생성

처음 사용 시 업장을 생성합니다. 업장을 생성한 사람은 자동으로 OWNER(소유자) 역할이 됩니다.

  • 업장 이름 — 예: 판교 아우디 서비스센터
  • 주소 — 예: 판교역로 10번길
  • 전화번호 — 예: 031-1234-5678

직원 초대

정비사와 접수 담당자를 업장에 초대합니다.

방법설명
전화번호로 초대직원의 전화번호를 입력하면 초대 링크가 SMS로 발송됩니다.
직접 초대이미 가입된 사용자를 검색하여 바로 초대합니다.

초대받은 사용자는 초대를 수락하면 업장에 합류합니다.

직원 관리

  • 역할 변경 — OWNER가 직원을 STAFF ↔ MANAGER로 변경할 수 있습니다.
  • 직원 내보내기 — MANAGER 이상이 직원을 내보낼 수 있습니다.
  • 업장 탈퇴 — 본인이 직접 업장을 나갈 수 있습니다.
Step 3

안전점검표 등록

차량 점검 시 사용할 안전점검표를 업장에 등록합니다. ACDelco 공식 점검표를 기본 제공합니다.

📋 점검표 선택
→
👁️ 미리보기 확인
→
✅ 업장에 등록
  • 20개 항목: 외관, 유리, 램프, 배터리, 오일류, 타이어, 브레이크, 서스펜션 등
  • 각 항목별 양호/권고 체크 + 코멘트 입력
  • 타이어 트레드 깊이, 브레이크 패드 두께 등 측정값 기록
등록된 점검표만 작업 시작 시 선택할 수 있습니다. MANAGER 이상의 권한이 필요합니다.
Step 4

고객 접수 및 작업 할당

수납 이력 자동 분석

고객의 수납 이력 엑셀 파일을 업로드하면 시스템이 자동으로 분석합니다.

👤

고객 정보 추출

고객명, 전화번호, 차량번호, 차종, 차대번호를 자동 식별합니다.

🔧

정비 이력 정리

정비 항목별 마지막 정비일과 주행거리를 요약합니다.

💳

최근 정비 내역

날짜순으로 정리하여 필요한 항목만 선택할 수 있습니다.

⚠️

권장 정비 안내

교환주기 초과 항목을 자동으로 안내합니다.

작업 할당

분석 결과를 확인한 후, 담당 정비사에게 작업을 할당합니다.

  • 담당 정비사를 선택합니다.
  • 작업 설명을 입력합니다 (예: 엔진오일 교환 및 브레이크 점검).
  • 선택한 정비 내역이 정비사에게 참고 정보로 전달됩니다.
접수는 웹 페이지(PC/태블릿)에서 진행합니다. MANAGER 이상의 권한이 필요합니다.
Step 5

점검 진행 및 서명

작업은 다음 상태를 거칩니다.

대기 중 → 점검 중 → 서명 대기 → 서명 완료 → 소견서 생성 중 → 소견서 완료

점검 시작

앱에서 대기 중인 작업을 선택하고 안전점검표를 선택하면 점검이 시작됩니다.

점검 진행

  • 각 항목을 양호/권고로 체크하며 점검합니다.
  • 타이어, 브레이크 등은 측정값을 직접 입력합니다.
  • 중간에 임시 저장하면 나중에 이어서 진행할 수 있습니다.
  • 고객 정보(이름, 연락처 등)도 점검 중 수정 가능합니다.

서명

  • 점검 완료 후 정비사 서명 → 고객 서명 순서로 진행합니다.
  • 정비사 서명은 마이페이지에서 미리 등록할 수도 있습니다.
  • 서명 완료 시 안전점검표 PDF가 자동 생성됩니다.

작업 취소

대기 중 또는 점검 중 상태의 작업은 취소할 수 있습니다.

AI는 어떻게 소견서를 작성하나요?

  1. 데이터 수집 — 안전점검표 결과(양호/권고/측정값), 고객 차량 정보, 접수 시 선택한 정비 이력을 하나로 모읍니다.
  2. 차종별 분석 — 해당 차종의 소모품 교환주기와 현재 주행거리를 비교하여 교체 시기를 판단합니다.
  3. 종합 소견 작성 — Claude AI가 20년 경력의 자동차 정비 전문가 관점에서 차량 상태를 평가하고, 즉시 조치가 필요한 항목과 다음 점검 시기를 안내합니다.
  4. PDF 자동 생성 — 분석 결과를 전문적인 소견서 양식으로 정리하여 PDF를 생성합니다.
모든 분석은 Anthropic Claude AI가 수행하며, 점검 데이터와 정비 이력을 기반으로 객관적인 소견을 제공합니다. 소견서는 참고 자료이며, 최종 판단은 담당 정비사가 합니다.
